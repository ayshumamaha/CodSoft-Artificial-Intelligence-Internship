# Movie Recommendation System Using Python

## 1. Project Overview

The Movie Recommendation System is a Python application that suggests movies based on a movie selected by the user. It uses content-based filtering to compare movie genres and descriptions and identify similar movies.

The project demonstrates recommendation algorithms, text processing, TF-IDF vectorization, and cosine similarity.

## 2. Objectives

- Develop a movie recommendation system using Python.
- Understand content-based filtering.
- Prepare and process a movie dataset.
- Calculate similarity between movie descriptions.
- Recommend movies based on user selection.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Libraries:** Pandas, Scikit-learn
- **Techniques:** TF-IDF and Cosine Similarity
- **Editor:** VS Code / Jupyter Notebook

## 4. Features Implemented

- **Movie Dataset:** Contains sample movie information.
- **Text Processing:** Processes genres and descriptions.
- **Feature Extraction:** Converts text into numerical vectors.
- **Similarity Calculation:** Compares movie content.
- **Movie Recommendations:** Suggests similar movies.
- **User Interaction:** Accepts movie selections.

## 5. Application Workflow

1. Load the movie dataset.
2. Process movie information.
3. Convert descriptions into TF-IDF features.
4. Calculate cosine similarity.
5. Accept a movie title.
6. Find similar movies.
7. Display recommendations.

## 6. How to Run the Project

1. Install Python.
2. Install the required libraries:

   `pip install pandas scikit-learn`

3. Save the code as `recommendation.py`.
4. Run the program:

   `python recommendation.py`

5. Enter a movie title to view recommendations.

## 7. Expected Output

The application displays a list of movies similar to the movie selected by the user.

## 8. Conclusion

The Movie Recommendation System demonstrates how content-based filtering can be used to suggest relevant items. It provides practical experience in data processing, feature extraction, similarity calculation, and personalized recommendations using Python.
