# Rule-Based Chatbot Using Python

## 1. Project Overview

The Rule-Based Chatbot is a simple Python application that responds to user messages using predefined rules. It identifies common inputs such as greetings, questions, and help requests and displays suitable responses.

The project demonstrates basic chatbot development, keyword matching, string processing, and conditional statements.

## 2. Objectives

- Develop a simple chatbot using Python.
- Understand rule-based response generation.
- Identify user messages using keywords.
- Generate predefined responses.
- Practise conditional statements and string manipulation.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Concepts:** If-Else Statements and String Processing
- **Technique:** Keyword Matching
- **Editor:** VS Code / Python IDLE

## 4. Features Implemented

- **Greeting Recognition:** Identifies common greetings.
- **Keyword Matching:** Checks user messages for predefined words.
- **Automatic Responses:** Provides suitable predefined answers.
- **Unknown Query Handling:** Displays a default response.
- **Interactive Chat:** Supports multiple messages.

## 5. Application Workflow

1. Start the chatbot.
2. Enter a message.
3. Process the message.
4. Match it against predefined rules.
5. Select and display a response.
6. Continue until the exit command is entered.

## 6. How to Run the Project

1. Install Python.
2. No external libraries are required.
3. Save the code as `rule_chatbot.py`.
4. Run the program:

   `python rule_chatbot.py`

## 7. Expected Output

The chatbot displays a welcome message and accepts user inputs. It responds to greetings, common questions, and help requests using predefined rules.

## 8. Conclusion

The Rule-Based Chatbot demonstrates basic chatbot development using Python. It provides practical experience in keyword matching, conditional statements, and interactive programming.
