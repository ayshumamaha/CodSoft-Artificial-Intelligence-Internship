# Tic-Tac-Toe AI Using Python

## 1. Project Overview

The Tic-Tac-Toe AI is a Python game in which a human player competes against a computer-controlled opponent. The AI uses the Minimax algorithm to evaluate possible moves and select the best move.

The project demonstrates game development, artificial intelligence, recursion, and decision-making.

## 2. Objectives

- Develop a Tic-Tac-Toe game using Python.
- Implement an AI opponent.
- Understand the Minimax algorithm.
- Practise recursion and game-state evaluation.
- Detect winning and draw conditions.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Algorithm:** Minimax
- **Concepts:** Recursion and Game Theory
- **Editor:** VS Code / Python IDLE

## 4. Features Implemented

- **Game Board:** Displays a 3 × 3 grid.
- **Human Player:** Allows the user to enter moves.
- **AI Opponent:** Selects moves using Minimax.
- **Win Detection:** Identifies winning combinations.
- **Draw Detection:** Detects a draw.
- **Input Validation:** Prevents invalid moves.

## 5. Application Workflow

1. Initialize the game board.
2. Display the board.
3. Accept the human player's move.
4. Evaluate possible moves using Minimax.
5. Make the AI move.
6. Check for a winner or draw.
7. Display the final result.

## 6. How to Run the Project

1. Install Python.
2. No external libraries are required.
3. Save the code as `tictactoe_ai.py`.
4. Run the program:

   `python tictactoe_ai.py`

## 7. Expected Output

The program displays a Tic-Tac-Toe board. The user plays as X, while the computer plays as O. The AI selects moves automatically and displays the final game result.

## 8. Conclusion

The Tic-Tac-Toe AI demonstrates the use of the Minimax algorithm for game-playing artificial intelligence. It provides practical experience in recursion, decision-making, and game development using Python.
