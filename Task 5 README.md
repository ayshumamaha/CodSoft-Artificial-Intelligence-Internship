# Face Detection Using Python and OpenCV

## 1. Project Overview

The Face Detection application is a Python-based computer vision project that identifies human faces in images using a pretrained Haar Cascade classifier. It draws rectangular boxes around detected faces and saves the processed image.

The project demonstrates image processing, face detection, and computer vision using OpenCV.

## 2. Objectives

- Develop a face detection application using Python.
- Understand basic computer vision concepts.
- Use a pretrained Haar Cascade classifier.
- Detect faces in images.
- Display and save processed images.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Library:** OpenCV
- **Technique:** Haar Cascade Face Detection
- **Supporting Library:** NumPy
- **Editor:** VS Code / Python IDLE

## 4. Features Implemented

- **Image Input:** Accepts an image path.
- **Image Processing:** Converts images into grayscale.
- **Face Detection:** Detects faces using Haar Cascade.
- **Face Marking:** Draws boxes around detected faces.
- **Output Saving:** Saves the processed image.
- **Error Handling:** Handles invalid image paths.

## 5. Application Workflow

1. Load the Haar Cascade classifier.
2. Enter an image path.
3. Read the image.
4. Convert the image to grayscale.
5. Detect faces.
6. Draw boxes around detected faces.
7. Display and save the output image.

## 6. How to Run the Project

1. Install Python.
2. Install OpenCV:

   `pip install opencv-python`

3. Save the code as `face_detection.py`.
4. Run the program:

   `python face_detection.py`

5. Enter the image path when prompted.

## 7. Expected Output

The application displays the input image with rectangular boxes around detected faces and saves the processed image as `detected_faces.jpg`.

## 8. Conclusion

The Face Detection project demonstrates how OpenCV and Haar Cascade classifiers can be used to identify faces in images. It provides practical experience in image processing and computer vision using Python.
